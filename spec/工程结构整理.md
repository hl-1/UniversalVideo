# 工程结构整理

日期：2026-10-19。用户已授权按工程整理建议实施；本记录说明实际调整边界。

## 目标与范围

采用模块化单体，保留单个 FastAPI 后端与 Vue 前端。整理目录和依赖，不增加用户功能。

1. 将后端业务移入 `backend/modules/`，基础能力移入 `core/` 和 `infrastructure/`。
2. 将原 `main.py` 中的请求模型、平台解析、字幕、总结、下载任务、批量下载和接口拆至对应模块；`main.py` 保留 Uvicorn 入口，`application.py` 负责应用组装。
3. 提取公共数据库连接、配置和迁移协调；解除账号连接依赖音乐库实现的关系。
4. 前端按 `app/`、`features/`、`shared/` 组织。拆分主组件与视频工具区，将验证会话、总结和下载流程提取为组合函数，通用请求工具迁至 `shared/api/`。
5. 前后端测试统一归入测试目录。保留已有测试场景，调整导入和测试替身目标。POSIX 目录权限断言仅在支持权限位的平台执行，Windows 继续验证账号目录和浏览器上下文隔离。
6. 合并 `spec/features/` 至 `spec/features/`；历史文档归入 `docs/archive/`，补充当前架构与开发指南。
7. 依赖安装移至 `scripts/setup.ps1`，日常启动不安装；新增并行测试入口 `scripts/test.ps1`。

## 接口、文件与运行兼容

- 启动入口为 `backend.main:app`，开发地址为 `http://127.0.0.1:5174/`，后端端口为 `8001`。
- API 路径、请求与响应模型、认证、媒体 Range 请求和 Service Worker 继续按既有契约运行。
- 配置优先级、下载与导出目录、模型路径、浏览器用户目录、备份目录保持兼容。
- Vue 工作区继续保持挂载，播放器与历史恢复流程保留。
- Python 内部导入路径按新目录调整；外部自编脚本若导入旧业务模块，需要同步使用新模块路径。命令行启动入口保持稳定。

## MySQL 数据明细

本次没有新增或修改 MySQL 表、字段、索引、关系或数据格式，因此无新增表结构或 DDL。原迁移函数的 SQL、执行顺序、事务边界和备份位置保留；仅由 `backend/migrations/` 集中协调。测试使用原有独立测试数据库流程。

## Redis 数据明细

本次没有新增或修改 Redis key 模板、示例、类型、值结构、TTL、读写、失效及一致性规则。既有认证、视频缓存和 Agent 缓存代码归入相应模块；原 key 和生命周期继续有效。

## 迁移与回滚

源码迁移时同步调整 Python、TypeScript、Vue、脚本与文档引用；不移动用户下载、凭证、模型或浏览器会话。无需数据迁移，不额外执行数据回滚。

若需要回退，整体恢复本次源码和文档变更，重新构建前端，重启本项目原端口服务；不要只回退部分模块。MySQL 和 Redis 仍使用原有结构与数据，不清库、不删除 key。
