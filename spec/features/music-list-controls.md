# 歌曲列表共用筛选与时间排序

## 功能与范围

所有主要歌曲列表统一提供歌手下拉、当前列表关键词搜索、搜索范围（歌名和歌手／仅歌名／仅歌手）、模糊／精确匹配、时间排序及重置。默认全部歌手、空关键词、歌名和歌手、模糊匹配及原始顺序。控件展示“匹配 N / 已加载 M 首”；仅处理已加载数据，不承诺检索完整平台或超过接口已有上限的个人曲库。

接入本地音乐、我喜欢、最近播放、试听、自建歌单、本站音源、下载管理的已保存／待核实记录、单曲搜索结果、批量找歌名单、场景歌单结果、今日推荐及首页歌曲区域、播放器队列。首页先筛选已加载完整集合，再取六首摘要；移动端继续显示最多三首摘要，可通过查看全部打开完整列表。任务进度、执行日志、候选选择下拉和偏好设置中的辅助名单保留各自交互。

桌面普通表格在歌曲和来源之间增加时间列，表头可按“默认 → 最新 → 最早 → 默认”切换，与工具栏排序选择同步。普通工具栏搜索框以 160px 为基准，空间不足时可缩小，宽屏不随剩余空间拉长；搜索、歌手和排序等选项从左侧紧凑排列，移动端及窄版播放队列继续由网格分配可用宽度。工具栏使用统一高度、8px 圆角、轻透明底色及自绘下拉箭头；时间选项直接显示“收藏时间 · 默认／新到旧／旧到新”等语义。歌手及排序带辅助图标，悬停／聚焦使用主题色反馈，颜色沿用当前音乐主题和背景。此次仅调整共用控件的 CSS 尺寸，无 MySQL、Redis 或设备存储变更。

手机（宽度不超过 760px）默认仅显示一行“搜索框＋筛选按钮”，下方显示匹配及已加载数量，四个高级选项和重置收进底部面板。按钮角标统计非默认的歌手、范围、匹配方式和排序条件，关键词直接显示在搜索框中，不重复计入角标。面板中修改立即生效，底部“查看 N 首歌曲”、关闭按钮、点击遮罩、Escape 和 Android 返回键均可收起，重置清除包括关键词在内的全部条件。采用原生模态 dialog 限制焦点，关闭恢复触发按钮焦点；面板打开时禁止背景滚动，关闭、切换桌面宽度或组件卸载后恢复。短屏只滚动选项区域，操作区保持可见，底部保留安全区；面板脱离播放队列的裁切区域并沿用音乐主题。无时间时在面板提示并禁用排序，时间仍展示在歌曲辅助信息中。输入使用 16px 字号，按钮触控高度不小于 44px；搜索回车收起键盘，不提交外层在线搜索表单。本次移动端收起交互只改变共用控件及队列样式，无 MySQL、Redis 或设备存储变更。

## 共用模块

- `musicList.ts`：无 Vue 或网络依赖的匹配、歌手选项、稳定排序、时间格式化；可注入字段适配函数，保留原歌曲对象及其业务字段。
- `useMusicList.ts`：管理会话内各列表作用域的条件及派生结果，同一列表重新挂载可恢复，切换账号清空。不同页面、歌单、搜索关键词及平台、导入任务、推荐批次、首页摘要及队列相互独立。不向 MySQL、Redis、localStorage 写入筛选偏好。
- `components/MusicListControls.vue`：通过 v-model 接收条件，以 props 展示歌手选项、数量、时间能力及文案，统一桌面／手机交互。
- `MusicTrackList.vue`：复用模块渲染普通表格；搜索、导入、推荐和队列保留专有歌曲行布局并调用相同逻辑。

过滤顺序为歌手、关键词、时间排序、分页／摘要截取。不会排序或覆盖原数组，不改变导入行 ID、推荐证据位置和原始排名。推荐曝光监听随可见列表更新，继续记录原始曲目身份和位置。

## 匹配、勾选与播放

文本使用 Unicode NFKC、首尾去空格及大小写归一化；保留版本词、内部空格及标点，不把 Live、伴奏等版本自动视为原版。模糊为字段包含，精确为完整字段相等；综合范围匹配歌名或歌手任一字段。歌手字段为空时使用 uploader；下拉提供未知歌手。合唱使用明确分隔符（顿号、中文逗号、分号、带空格的 `/`、`&`、feat）识别单个歌手，保留 AC/DC 等名称。精确搜索可以匹配完整合唱字段或其中一个明确歌手。

歌手选项来自原始已加载集合，按规范化姓名去重。实时刷新导致所选歌手暂时无歌曲时保留该条件并提示，用户可重置。无匹配时显示提示，清空／重置恢复结果。

批量名单先对全部已加载行筛选，再按 50 行分页，条件改变回到第一页。原有匹配状态筛选与新条件叠加。筛选本身保留隐藏歌曲的勾选；全选作用于当前筛选结果，保存／下载按钮仍显示全部已选数量，原批次上限继续有效。主动使用快捷选择可重新指定选择集合。场景页“下载全部在线歌曲”继续明确针对全部原始在线结果。

普通列表、搜索和推荐列表点击歌曲／播放全部时，使用当前筛选排序结果作为播放列表。队列筛选、排序仅改变队列面板展示，点击其中歌曲继续使用完整已有队列；清空和移除操作沿用原规则。首页摘要播放使用筛选后的完整已加载集合。

## 列表刷新与位置保持

已有歌曲时，音乐库刷新保留当前列表组件和歌曲行，数据返回后原地更新；加载动画仅用于没有已有歌曲的首次加载或页面切换。首页“继续聆听／本地音乐”摘要遵循相同规则，筛选为空时也保留原筛选条件。刷新失败保留已有歌曲并显示错误。

喜欢／取消喜欢、播放及切歌保存历史、加入已有歌单、移除记录、导入／上传、文件重新授权、封面补全等操作不得通过卸载整张列表造成页面高度骤降和滚动归零。记录删除、筛选结果变化或历史时间更新导致的歌曲数量与顺序变化仍按原业务规则生效；列表缩短至当前位置之外时允许浏览器补位。主动切换页面或歌单仍按原导航规则回到顶部。

本次位置修复只调整前端渲染，不新增或修改 MySQL 表、列、完整表结构、索引、外键及关系；不新增或修改 Redis key、模板、示例、类型、值结构、TTL、读写、失效及一致性规则。沿用现有接口和设备存储，无数据迁移；回滚仅撤销本次前端渲染改动并重新构建、按原端口重启前端，无需处理业务数据。

## 时间数据契约

`MusicTrack.list_time` 为可选的 Unix 秒（可含小数）或 null，表示所在列表的记录时间，不是歌曲发行时间。服务端只补充返回已有关系／文件记录时间，不将首次索引时间、刷新时间或结果序号当作时间。

| 列表 | 时间来源 | 文案 |
| --- | --- | --- |
| 喜欢 | music_favorites.created_at | 收藏时间 |
| 最近播放／试听 | music_history.played_at | 播放时间 |
| 自建歌单 | music_playlist_tracks.added_at | 加入时间 |
| 兼容服务器下载列表 API | music_downloads.created_at | 记录时间 |
| 本地音乐（浏览器） | IndexedDB DeviceEntry.added_at，毫秒转换为秒 | 导入时间 |
| 本地音乐（Android） | 已有 Room OfflineRow.createdAt，桥接返回 Unix 秒 | 导入时间 |
| 本设备保存记录 | 已有 file_confirmation.saved_at，毫秒转换为秒 | 保存时间 |
| 本站音源 | music_server_assets.created_at | 上传时间 |
| 在线、导入匹配、场景及今日推荐、队列 | 仅使用曲目已有的明确 list_time | 记录时间 |

相同时间保留原始相对顺序，升／降序均将缺失或无效时间放最后。无效包括非正数、非有限值及超出 Date 范围的时间。日期按浏览器本地时区显示到分钟，排序仍使用完整时间精度。全部缺失时显示“暂无时间信息”，禁用时间升／降序及表头，保留默认顺序；不得从本轮刷新补造时间。旧 Android 桥接缺少时间时也显示未知，不重复写入 Date.now()。安装包含该桥接改动的新包后才能取得原生离线记录的真实时间；网页兼容旧包。

## MySQL、Redis、设备存储、迁移与回滚

MySQL 无新增或修改表、列、完整表结构、索引、外键及关系；只读取上表已有字段，沿用账号资源归属检查和接口已有最多 1000 首限制。本次没有 DDL、Flyway 新版本或数据回填，因此无新增表结构和迁移 SQL。`/api/library/tracks` 和 `/api/music/site/tracks` 添加可选响应字段 list_time，原字段及默认查询顺序保持兼容，旧客户端忽略新增字段即可。

Redis 无新增或修改 key，因此无新增模板、示例、类型、值结构、TTL、读写、失效及一致性规则。筛选结果在浏览器响应式计算，不新增 Redis 缓存或数据库双写。

IndexedDB、localStorage 保存凭据和 Android Room 均复用已有时间字段，无 schema/version 变化，无音频复制、重新导入或历史记录重命名。筛选条件仅为会话内存状态，账号变化清空。回滚对应前后端和可选原生桥接代码、重新构建并重启应用即可；不删除表、缓存、设备文件或业务数据。
