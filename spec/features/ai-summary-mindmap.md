# AI 总结思维导图规格

## 目标

基于视频字幕或转写文本生成结构化思维导图。联合任务在文本就绪后与总结并行生成；已有总结仍可单独生成或重新生成导图。前端使用经典曲线脑图画布，支持节点折叠、缩放、平移、适应画布、历史恢复和时间戳跳转，不实现问答或向量检索。

## 数据契约

- `MindMapNode` 包含 `id`、`title`、`summary`、`timestamp`、`segment_ids`、`children`。
- `MindMapResult` 包含 `title`、`nodes`、`generated_at`。
- 节点最大深度为 4，每个节点最多 10 个子节点。
- 标题最长 80 字，说明最长 300 字。
- 模型只返回标题、说明、字幕索引和子节点；后端生成稳定 ID，并从有效字幕引用回算时间戳。
- 删除空标题、无有效字幕引用和完全无效的节点。清洗后无节点时任务失败。

## 接口

- `POST /api/summaries/{task_id}/mind-map` 创建任务；查询参数 `regenerate=true` 可强制重生成。
- `GET /api/summaries/{task_id}/mind-map` 查询任务。
- 查询可用 `map_id` 指定版本，响应可选携带 `timing` 与 `model_info`；先校验账号和持久化版本归属，再返回对应运行任务的实时计时，否则读取持久化快照。
- 状态为 `pending`、`running`、`finished`、`failed`、`cancelled`。
- 单独创建接口在总结不存在、未完成或失败时拒绝创建。
- 同一总结默认复用现有 pending、running 或 finished 任务。
- `POST /api/summaries` 传 `generate_mind_map=true` 自动预建关联导图，返回 `mind_map_task_id`，此模式不要求总结正文先完成。字幕提取失败时结束预建导图；模型阶段两侧独立失败和保存。

## AI 与安全

- 复用当前账号/本地的 OpenAI 兼容配置；联合任务与总结使用同一份固定配置，结果记录实际模型和服务主机名，不返回密钥。
- 使用 JSON 输出并通过 Pydantic 与后端清洗器双重校验。
- Prompt 要求只能依据字幕，不得补充字幕中不存在的事实。
- 新生成的内容以首屏知识概览为目标：中心主题提炼为约 8–16 字，去掉课程宣传和系列前后缀；按知识或论点关系归类，同主题的重复讲解、操作演示、示例及结尾回顾合并。通常 4–6 个主主题、每个 2–3 个关键点、包含中心在内约 25 个节点以内；标题约 6–12 字，说明使用一至两句，保留字幕依据。以上是提示词目标，清洗仍沿用 4 层 / 每级 10 个子节点的兼容上限，不为了满足数量硬裁剪已保存节点。
- 本次不增加模型请求。普通视频仍一次导图调用，长文本仍分块并行、按既有规则归并；没有增加跨分块的语义归并请求，分块边界处的同义主题仍可能需要后续优化。
- 不重新提取字幕，不使用弹幕，不返回 API Key。
- 长文本按原有大小分块，最多并行 2 个分块，按原字幕顺序归并并保留字幕引用；不以截断导图输入换取速度。
- 采用共用请求限制、显式超时和可取消重试规则，详见[总结规格](ai-video-summary.md)。

## 前端

- 总结结果提供“总结 / 字幕 / 思维导图”标签页。
- 导图可在总结正文完成前查看；任一侧失败保留另一侧结果。执行耗时区域按总结与导图分组展示阶段状态及具体耗时；完成阶段统一绿色满条，执行中为蓝色进度，失败或取消使用独立状态标记。总耗时按实际并行执行跨度计算，详情包括导图分段及请求次数，具体展示规则见 [AI 视频总结规格](ai-video-summary.md)。
- 首次导图布局耗时由画布独立上报；单独重新生成导图的总耗时从新任务开始计，不包括两次用户操作的间隔。
- 使用 Mind Elixir 只读模式呈现中心居中、左右展开的经典脑图：中心为浅紫色圆角主题框，一级主题使用分支同色描边，子分支继承一级分支颜色。按可见子树的预计行数分配左右方向，优先安排较大分支，保持各侧原有节点顺序。
- 默认“概览”，展示全部主主题并尝试展示关键点，保留底层完整节点。可见节点超过 25 个或适配后的 14px 标签字号将小于约 12px 时，退为主主题概览；小于 640px 的窄屏直接使用主主题概览。概览中的长标题省略显示，完整标题及说明在点击后的节点详情面板中查看，时间入口保留在详情中。
- 概览不展示长说明和逐节点时间标签；“详细”展示完整标题、说明和时间戳，可展开全部内容。提供“全部收起 / 全部展开”、缩放、适应画布和全屏查看；“全部收起”保留全部一级主题。
- 手机概览收紧主分支间距并使用 15px 标签，避免内联主题间距让整图过度缩小；实际显示字号仍取决于画布及标题长度。说明文字在节点详情中按正常字号阅读。
- 初始显示及“适应画布”以中心节点为锚点，按左右、上下较大伸展范围计算缩放，中心节点对齐画布中心；自动适配不额外放大。手动缩放范围为 0.2–1.6。
- 概览由当前画布大小即时计算，不写入历史视图，首次打开及切回概览均重新适配。详细模式沿用既有缩放、位置和折叠状态恢复，布局完成前不保存临时位置；尺寸变化时更新布局，概览重新计算可见层级。
- 支持节点展开/收起、画布缩放、拖拽平移和一键适应画布；画布底部提供水平滑动条，其可移动范围按导图完整宽度计算，拖拽、缩放、折叠和历史视图恢复后同步实际位置。
- 保留 Mind Elixir 的指针事件处理，通过容器样式隐藏原生滚动条，确保只读模式下仍能拖拽画布、点击节点折叠控件及使用滚轮浏览。
- 不允许用户编辑、拖动节点或删除节点。
- 点击节点打开详情面板，可查看完整说明及子节点；当前平台存在在线预览时可点击时间戳跳转播放器，否则禁用时间入口。
- API 数据必须经过 runtime filter，再转换为 Mind Elixir 数据；所有进入自定义节点 HTML 的文本必须转义。
- 画布工具栏提供下载图标，菜单内可选择“概览图 / 完整详细图”和 SVG / PNG 格式；支持键盘选择、Escape 关闭和点击外部关闭，导出期间禁用重复操作，失败显示可重试提示。
- 在浏览器内使用独立的 Mind Elixir 画布计算双侧导图布局。概览图保留当前概览中实际展开的节点、短标题及彩色连线；完整图展开全部节点，保留完整标题、说明和时间戳。图片不包含工具栏、滑动条和折叠控件。
- 导出不受当前缩放、平移影响，完整图不受折叠或手机端隐藏说明影响，不修改现有画布和已保存视图。等待字体和布局完成后，将节点、文字行和连线统一换算为导出坐标，以原生 SVG 的 rect、path、text/tspan 输出；文字逐行固定坐标和宽度，不嵌入 foreignObject、HTML、CSS zoom 或需要查看器重新排版的样式，避免系统图片预览遗漏深层节点。
- SVG 使用系统中文字体及后备字体，保留可缩放、可选择的文字；不同设备的字体外观可能略有差异。PNG 从同一份原生 SVG 生成，使用白色背景和 2 倍分辨率。
- 文件名使用清洗后的导图标题及对应扩展名；导出完成或失败后销毁独立画布，下载后释放临时 URL。
- 不实现 PDF 导出。

## 导出数据与兼容

- MySQL：图片从已有 `MindMapResult` 在客户端生成，无新增或修改的表、字段、索引和关系，不存储图片或导出任务，不涉及数据库迁移。
- Redis：无新增或修改的 key、类型、值结构、TTL 和读写规则；导出不使用 Redis，无新增缓存失效或一致性要求。
- 兼容与回滚：沿用现有导图接口和节点契约；移除 SnapDOM 依赖。已有 SVG 文件需重新导出才能使用新的兼容格式；回滚前端导出代码及对应依赖即可，不需要数据回滚。

## 生成耗时数据与兼容

- MySQL：无 DDL、索引或关系变更。沿用 `video_mind_maps` 的 `summary_task_id`、`version`、账号归属及 `content` JSON，新增可选 `timing` 和 `model_info`；总结 JSON 保存自动导图 ID。完整既有表结构、JSON 契约和回滚说明见[性能记录](../performance/ai-video-generation-2026-10-19.md)。
- Redis：无新增或修改的 key、类型、值结构、TTL、读写及失效规则。耗时随已有 MySQL 快照持久化，不依赖 Redis。
- 历史任务没有计时数据时显示“未记录”；服务中断后冻结最后快照，排除未知停机时长。移除新增代码即可回滚，无数据迁移。

## 布局数据与兼容

- MySQL：沿用现有视图中的 `map_view`（`scale`、`x`、`y`、`collapsed`），无新增或修改的表、字段、索引和关系；布局及滑动条状态由客户端计算，无数据库迁移和数据回滚。`scale` 的接口校验范围修正为 0.2–1.6，与已有画布实际缩放范围一致；阅读模式、概览层级和临时节点详情不新增持久化字段。
- Redis：布局不使用 Redis，无新增或修改的 key、值结构、TTL、读写和失效规则，无新增一致性要求。
- 兼容与回滚：旧结果可直接使用概览，不改写原有节点；新的知识归类规则只影响重新生成的版本。详细模式保留历史视图恢复能力，初始概览与“适应画布”使用中心居中策略。回滚生成提示词、前端画布 / 适配 / 导出 / 样式及缩放校验即可恢复原行为，无数据迁移或回滚。

## 测试

- 后端覆盖合法树、非法 JSON、空结果、深度和子节点裁剪、非法字幕引用、时间戳回算、任务复用与强制重生成。
- 前端覆盖 runtime filter、递归深度、Mind Elixir adapter、HTML 转义、失败重试和时间戳跳转 helper。
- 导出回归覆盖完整节点和多行文字、中文与 XML 特殊字符、节点及连线坐标、非法尺寸，以及 SVG 不包含 foreignObject/HTML/CSS zoom；使用含深层节点的导图检查 SVG 和 PNG 内容一致。
- 浏览器验证桌面和手机端 SVG/PNG 下载、完整节点与说明、中文及特殊字符、折叠和缩放后的内容完整性、视图不变、错误提示与重试、临时画布清理及导出菜单操作。
- 浏览器验证概览的根节点居中、左右分配、可见节点适配、窄屏主主题覆盖、节点详情、全屏、模式切换、详细视图恢复、双侧横向浏览及两类导出；概览的自动适配不覆写详细模式的历史视图。
